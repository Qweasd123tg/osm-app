# Shade Map

Этот каталог содержит автономный Python-эталон слоя теней из монорепозитория
`osm-app`. Сохранённые исходные данные лежат в `cache/`, а готовые карты — в
`examples/`. Он используется для статического экспорта и остаётся эталоном для
будущих golden-сравнений с Android-реализацией, но не запускается в APK и не
служит runtime-backend.

Генератор статических HTML-карт с тенями от зданий по данным OpenStreetMap.
Python загружает и нормализует геометрию OSM, рассчитывает положение солнца и
сохраняет готовую 2D- или 3D-карту. Для просмотра карты локальный сервер не
нужен, но библиотеки карты и подложка загружаются из интернета.

## Возможности

- обычные здания, `building:part` и multipolygon relations;
- внутренние контуры зданий и открытые дворы;
- высота из `height`, `building:levels` или эвристики по типу и площади;
- `min_height` и `building:min_level` для приподнятых частей;
- расчёт геометрии в локальных метрических координатах;
- единая тень без искусственного затемнения пересечений;
- шкала времени на весь день и автоматическое воспроизведение движения тени;
- отдельный слой достоверности высот;
- 2D-карта Folium и 3D-карта MapLibre.

## Установка

Проект имеет собственные зависимости и больше не использует окружение из
каталога `ветер`:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e .
```

После установки доступны команды `shade-map` и `shade-map-3d`. Скрипты также
можно запускать напрямую через `python shade_map.py` и `python shade_3d.py`.

Android получает новые сырые районы OSM напрямую по HTTPS, кэширует их и
выполняет нормализацию, расчёт солнца и lazy-геометрию теней локально. Не
запускайте из этого каталога сервер для приложения: Python остаётся независимым
инструментом генерации и проверки результатов.

## 2D-карта

```bash
shade-map \
  --bbox 59.93097,30.32310,59.93733,30.34590 \
  --time 2026-07-17T15:00:00+03:00 \
  --cache cache/spb_center_buildings.json \
  --label "Центр Санкт-Петербурга" \
  --output index.html
```

Если `--time` не передан, используется текущее локальное время. Переданное
время обязательно должно содержать часовой пояс, чтобы результат не зависел от
настроек компьютера.

## Управление временем

Обычная генерация сразу рассчитывает кадры на весь выбранный день. В готовой
карте можно перетаскивать ползунок или нажать кнопку воспроизведения. Ночные
кадры остаются пустыми, поскольку солнце находится ниже горизонта.

По умолчанию шаг составляет 30 минут. Меньший шаг делает движение плавнее, но
увеличивает время генерации и размер HTML:

```bash
shade-map --time-step-min 15 --workers 4
```

Для быстрого статического файла можно отключить временную шкалу:

```bash
shade-map --no-animation
```

Точное время из `--time` всегда добавляется отдельным кадром, даже если оно не
совпадает с регулярным шагом.

## 3D-карта

```bash
shade-map-3d \
  --bbox 59.8458,30.3100,59.8584,30.3358 \
  --time 2026-07-17T15:00:00+03:00 \
  --cache cache/moskovskaya_buildings.json \
  --label "Метро Московская" \
  --output 3d.html
```

## Кэш OSM

Кэш связан с конкретным `bbox`, версией запроса и размером загруженной области.
Поэтому старые данные другого района больше не могут быть использованы молча.

```bash
shade-map --refresh
```

При обновлении запрос расширяется на максимальную длину тени, чтобы учитывать
здания за границей отображаемого прямоугольника. Старые кэши без этого запаса
продолжают работать с предупреждением; достаточно один раз выполнить
`--refresh`. Если основной публичный Overpass endpoint временно недоступен,
загрузчик автоматически пробует резервный.

Длину тени и одновременно размер запаса можно изменить:

```bash
shade-map --max-shadow-m 500 --refresh
```

## Тесты

```bash
python -m unittest discover -v
```

Тесты проверяют входные параметры, привязку кэша к району, multipolygon с
двором, незамкнутые OSM ways, метрическую проекцию, тени от приподнятых частей,
ночное время, временную сетку и безопасную сериализацию данных в HTML.

## Файлы

- `shade_map.py` — OSM, геометрическое ядро и 2D-экспорт;
- `shade_3d.py` — 3D-экспорт MapLibre;
- `cache/*.json` — кэш ответов Overpass;
- `tests/` — регрессионные тесты;
- `examples/2d.html` и `examples/3d.html` — сохранённые готовые примеры.

## Ограничения

Это геометрическая модель плоской земли, а не трассировка света. Она не
учитывает рельеф, деревья, форму крыш, прозрачные конструкции и отражённый свет.
Качество результата сильно зависит от полноты высот в OpenStreetMap; слой
`Height confidence` показывает источник оценки каждого здания.
