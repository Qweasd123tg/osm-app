# Web examples

- `2d.html` — Folium/Leaflet-карта центра Санкт-Петербурга;
- `3d.html` — MapLibre-карта района Московской и источник данных Android-демо.

Оба файла содержат здания и 49 рассчитанных кадров теней. Их можно открыть
напрямую в браузере; интернет потребуется для библиотек и растровой подложки.

После обновления `3d.html` запусти из корня репозитория:

```bash
python tools/build_map_data.py
```

Команда синхронизирует 3D-пример с `app/src/main/assets/map-data.js`.
